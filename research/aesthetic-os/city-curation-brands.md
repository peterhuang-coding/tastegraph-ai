## 1. Humans of New York (HONY)

### 时间线
- 2010/09–11 由 **Brandon Stanton** 在纽约街头拍照 + 引用语做 blog 起步。
- 来源：Wikipedia "Humans of New York"

### 流量
- 2025：**跨平台 30M+ 粉丝**。
- 2024/05：**Facebook 17M+ likes**。

### 出版物（**全部 NYT #1 Best Seller**）
1. *Humans of New York* — 2013/10（St. Martin's Press）— 2013、2014 Non-Fiction #1
2. *Humans of New York: Stories* — 2015/10
3. *Humans* — 2020/10（2020/10/25 上 #1）
4. *Tanqueray* — 2022（与 Stephanie Johnson 合作）

### 大人物专访
- 2015/01 Obama（Oval Office）
- 2016/09 Hillary Clinton

### 国际行
- 2012/12 Iran
- 2014/08 50 天 "World Tour" 12 国（Iraq / Jordan / Israel / DR Congo / Kenya / Uganda / South Sudan / Ukraine / India / Nepal / Vietnam / Mexico）
- 2015/08 Pakistan
- 2015 European migrant crisis（与 UNHCR 合作）
- 2018/09 Rwanda

### 慈善（**核心不是赚现金，是赚信任 + 媒体放大**）
- Hurricane Sandy（Tunnel to Towers 基金会）：目标 $100k → **$318,530**
- Vidal Chastanet / Mott Hall Bridges Academy：$1,419,509（51,476 贡献者）
- Syeda Ghulam Fatima / Bonded Labour Liberation Front：**US$2.3M+**
- Memorial Sloan Kettering 儿科癌症：**$3.8M+**（3 周 / 100,000+ 人）
- Headstrong Project（退伍军人）：目标 $100k → **$500k+**
- Gisimba Orphanage（Rwanda）：目标 $200k / **18 小时达成**
- 2020–2022 疫情：18 个月 NYC 个人 / 小企业 **~$8M**

### DKNY 侵权事件（**2013**）
- DKNY 在曼谷橱窗用了 HONY 照片未授权。Stanton 要 $100k → DKNY 捐 $25k，Stanton 自己在 Indiegogo 补到 $103k 给 YMCA Bedford-Stuyvesant。事件本身是 HONY 维权意识的标志性事件。

### 视频 / 装置
- *Humans of New York: The Series* — 2017/08/29 在 Facebook Watch 首播，**2017/12 是平台最受关注剧集**。
- 2025/10 "Dear New York"——Grand Central Terminal 两周沉浸式装置，与 MTA / Juilliard / NYC DOE 合作。Stanton 已去过 40+ 国。

### 收入来源（推断）
- 书籍版税（NYT #1 系列，4 本）
- TED / 演讲
- 视频内容授权（Facebook / Instagram Reels bonus）
- 装置 / 沉浸式体验（Grand Central 等）
- 慈善本身不是现金流来源，但是**信任 + 媒体放大器**

### 可迁移启示
**对一个审美图片推荐产品**：
1. **HONY 模式是"单 IP + 单作者 + 全渠道"的极限**——一个 Stanton 做完全部内容，35M 粉丝。我们不要做 100 个 KOL，要做 **"一个主理人 / 一个审美主张 + 全平台分发"**。判断指标是：**这个产品是不是能挂在一个名字上**？
2. **慈善是放大器不是现金流**。HONY 之所以能和 Obama / UNHCR / UNICEF 平等合作，是因为他"已经把公益做成基础设施"。我们可以**把"图源透明 + 创作者分成"做成美学版 HONY**——用户每收藏一张图，作者分成，同时平台对原作者社群做"美学公益"。
3. **DKNY 事件暴露了"美学 IP 侵权"的痛点**——大品牌会用你的内容不付费。我们的平台可以**做"创作者图源 API"**，让品牌合作默认经过平台分成。

## 2. Hidden NY / @thingstodoin / @hiddensf 等

### 现状（**无法访问官网，需补充**）
- 所有 .com / .nyc / .world 域名 + Wikipedia 词条都 404 / 403，调研不可验证。
- 间接信息（基于其他团队任务）：@hidden 系列账号是**同一运营方**的矩阵账号，覆盖 NYC / SF / Paris / London 等城市，发布"今天去哪儿"的精选内容。

### 推断模式（**待补充**）
- 矩阵账号 → 多城市分发 → 本地化 KOL → 餐厅 / 酒店 / 品牌广告分成 → 自己周边（Hidden Shop 卖 T-shirt / cap）
- 与 HONY 区别：**HONY 是单 IP / 单人物**；Hidden 是**多城市 + 多 KOL + 美学一致**。

### 可迁移启示
**对一个审美图片推荐产品**：城市策展账号的核心是**"信息密度 + 一致调性 + 局部稀缺"**。我们不需要做城市指南，但可以**做"美学城市主题包"**——每周推一个"Tokyo 极简夜 / 巴黎 Belle Époque / 上海 90s"主题包，附精选图片 + 起源图谱 + 可购买清单。这是**主题式订阅**而不是单图推荐。
