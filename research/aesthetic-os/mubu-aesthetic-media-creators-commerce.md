# 审美媒体、审美博主与商业闭环

## 1. 审美媒体
### 1.1 他们在做什么
- 选择：从大量内容中判断什么值得看
- 解释：说明为什么值得看、和哪些风格/文化有关
- 节奏：决定主题、频率、密度和发布仪式
- 承接：把审美延伸到书、物件、地点、体验、品牌和社群

### 1.2 四种媒体形态
- 编辑型杂志：季刊、专题、访谈、城市指南
- 城市/地点策展媒体：城市清单、地点故事、地图
- 文化垂直媒体：音乐、设计、时尚、展览、文化圈层
- 视觉策展平台：图片流、主题包、收藏、搜索

### 1.3 媒体工作链路
- 选题/主题
- 来源发现
- 编辑筛选
- 事实/版权核验
- 视觉编排
- 文字解释
- 多渠道分发
- 用户反馈
- 下一期选题

### 1.4 内容单元
- 单图判断：为什么这张图值得看
- 主题包：12–24 张图共同表达一个方向
- 风格邻居：从已知风格走向新风格
- 场景包：图片 + 地点 + 商品 + 音乐 + 材质/颜色
- 编辑档案：一个主理人/设计师/摄影师的完整品味

### 1.5 媒体节奏
- 每周 Editor's Note
- 每月 Guest Editor
- 每季 zine/季刊
- 每年 Top 100/年度趋势
- 固定 Drop Day
- City Walk/线下活动

## 2. 审美媒体怎么变现
### 2.1 低成本收入
- 订阅/会员：审美档案、完整推荐、风格流、Drop 提前权
- 出版物：季刊、年鉴、城市指南、限量 zine
- 联盟/导流：服装、鞋包、书籍、酒店、展览、体验

### 2.2 中期收入
- Drop：小批量主题物件、海报、卡片、tote、帽子、香片
- 联名：品牌/设计师/美术馆合作
- 体验导流：城市路线、咖啡馆、书店、展览、酒店
- B2B 策展：Campaign moodboard、品牌视觉方向、趋势报告

### 2.3 后期收入
- 审美评分/风格检索 API
- 品牌私有审美模型
- 商业授权图库
- 创作者 Marketplace
- Aesthetic Advisory

## 3. 审美博主
### 3.1 五类博主
- 视觉编辑型：会挑图、定义调性
- 街头观察型：现场、造型、城市视角
- 风格解释型：把感觉说清楚
- 选品/推荐型：降低购买决策成本
- 社群主理型：聚集同好、组织活动

### 3.2 博主核心资产
- 个人视角
- 稳定视觉签名
- 可重复的方法
- 用户信任
- 跨平台传播能力

### 3.3 博主工作链路
- 明确立场
- 固定视觉签名
- 形成栏目
- 解释选择
- 让用户参与 A/B 比较
- 沉淀用户审美偏好
- 推荐相关商品/地点/体验
- 形成交易或品牌合作

### 3.4 推荐栏目
- 今天的 1 张图
- A/B 审美二选一
- 一种风格的 5 个来源
- 街头造型拆解
- 一件商品的 3 种搭配
- 一座城市的审美路线
- 本周没有被看见的小品牌
- 编辑为什么拒绝这张图
- Guest Editor

### 3.5 博主商业升级
- 内容发布者
- 选品者
- 审美顾问
- 品牌共创者
- 商品/体验主理人
- 自有审美 IP

## 4. 跨平台打法
### 4.1 每个平台的任务
- 自有网站/小程序：用户、推荐、商品、交易数据资产
- 邮件/公众号/Newsletter：深度内容、留存、订阅
- 抖音/视频号：短视频发现、规模触达、商品承接
- Bilibili/YouTube：长视频、教育、信任、专题
- Instagram/Pinterest/Behance：视觉发现、作品集、国际传播
- 社群：A/B 反馈、预览、活动、共创
- 联盟/电商平台：商品履约、点击和订单归因

### 4.2 内容不能原样跨平台复制
- 自有平台：完整主题包 + 商品/地点关联
- Newsletter：编辑信 + 5 张主图
- 短视频：为什么这组图成立
- 长视频：城市路线/造型拆解
- 视觉平台：9 张视觉海报
- 社群：A/B 选择和下月主题投票
- 品牌提案：一页 campaign reference board

### 4.3 当前渠道边界
- 小红书账号侧目前暂停
- 不做账号自动化、评论、私信、账号抓取
- 其他渠道使用本人/团队有权管理的账号和官方能力
- 先建设自有承接面和一方数据

## 5. 内容到商业闭环
### 5.1 用户闭环
- 内容曝光
- 用户搜索/收藏/转发
- 进入自有承接面
- 完成 5–10 组审美 onboarding
- 建立个人审美档案
- 推荐内容/商品/体验
- 点击/加购/下单/报名
- 订单、退款、复购反馈
- 更新用户与商品关系
- 下一轮更好的推荐

### 5.2 四个分数要分开
- taste_fit：用户是否喜欢
- content_quality：内容质量
- commercial_fit：是否适合商品/品牌/场景
- business_value：佣金、利润、履约条件

### 5.3 商业排序原则
- 先通过相关性门槛
- 再通过安全/版权/品牌适用性
- 最后优化库存、履约和商业条件
- 不能高佣金就强行排前
- 商业内容要明确披露

### 5.4 必须记录的数据
- request_id
- session_id
- channel
- campaign_id
- user_id_hash
- item_id/product_id
- position
- retrieval_source
- model_version/feature_version
- organic_score/commercial_score
- propensity
- click/save/add_to_cart/order/refund

## 7. 90 天验证
### W1–2：内容和主理人
- 锁定一句审美立场
- 发布两个固定栏目
- 建立自有 landing page
- 记录来源、主题、渠道
- 准备 6 组 A/B 选择

### W3–4：一方用户池
- 跨渠道引导到自有页面
- 完成 5–10 组 onboarding pair
- 生成个人审美档案
- 鼓励收藏主题包

### W5–6：商品/地点导流
- 选择一个品类或城市体验
- 接入有权利和履约能力的合作方
- 使用 campaign_id/affiliate_id
- 记录点击、加购、订单、退款

### W7–8：第一个付费内容产品
- 城市审美主题包
- 风格年鉴/数字 zine
- 商品+视觉搭配清单

### W9–10：品牌策展 POC
- 找酒店、咖啡品牌、买手店或独立服装品牌
- 交付视觉 board、30 张参考图、商品/空间建议、风格禁区

### W11–12：阶段判断
- 用户是否主动回访
- 是否完成审美 onboarding
- 内容是否被保存/转发/引用
- 商品是否有有效点击和订单
- 是否有人愿意为内容或策展付费
- B2B 客户是否愿意续约

## 8. 指标
### 内容
- 合格观看率
- 收藏率
- 主题包完成率
- 外部引用率
- 自有平台回访率

### 审美学习
- onboarding 完成率
- pairwise 选择一致性
- 喜欢/隐藏比例
- profile 稳定性
- 新风格探索成功率

### 商业
- 商品详情页点击率
- 加购率
- 下单转化率
- 退款率
- 复购率
- 佣金/毛利
- 每个主题包收入

### B2B
- 提案接受率
- POC 付费率
- 续约率
- 推荐结果使用率
- 为客户节省的选品/创意时间

## 9. 关键原则
- 卖审美判断，不卖图片数量
- 媒体负责选择、解释、节奏、承接
- 博主负责视角、信任、方法和关系
- 第三方平台负责发现，自有平台负责沉淀
- 先相关性，再商业条件
- 交易反馈必须回流推荐系统
- 先小而准，后扩展品类和渠道
- 所有图片、账号、用户数据和商业合作都要有权利与披露边界
