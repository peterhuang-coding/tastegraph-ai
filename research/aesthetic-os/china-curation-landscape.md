## 1. Wallpaper*（英国 → 中文版）

### 主体
- 1996 由 **Tyler Brûlé**（加拿大）+ Alexander Geringer 在伦敦创办。
- 1997 卖给 Time Warner；后续进入 TI Media，最终被 **Future plc** 收购（现持有方）。
- 现 EIC: **Bill Prince**（2023 起）。
- 月刊，印刷流通 **100,460**，语言英文，London 总部。
- 每月 + 网站 + Bespoke（content creation / exhibitions / events 给客户）。
- 与 Phaidon Press 合作出版 100+ 本城市指南。

### 关键事件
- 2005/01 Wallpaper* Design Awards 启动。
- 2007 起每年 10 月 guest editor：Jeff Koons / Zaha Hadid / Karl Lagerfeld / David Lynch / Kraftwerk / Ole Scheeren / Elmgreen & Dragset / Frank Gehry / William Wegman / Jenny Holzer / Giorgio Armani / Yayoi Kusama。
- 2010–2019 米兰 Salone del Mobile 年度 Wallpaper* Handmade 展。
- 2015/10 出版第 200 期。
- **2017 中文版推出，与华盛传媒 Huasheng Media 合作**。
- 2008/08 与 Eyestorm 推出 *Wallpaper* Selects*（卖限量签名照片）。
- 2011/07 iPad 版上线。
- 2015 推出 WallpaperSTORE*（电商）。
- 2024 与 Rolex 合作出版 Submariner 历史。

### 收入来源
- 印刷订阅 / 单卖
- 数字内容 + 限量商品（Selects）
- B2B Bespoke（content / exhibitions / events）— 大头
- 广告（高单价，奢侈品 / 设计）
- 联名 / Guest Editor 模式（设计师 + 品牌）

### 可迁移启示
**对一个审美图片推荐产品**：
1. **"Guest Editor" 模式可复制**。Wallpaper* 每年请一位艺术家做 10 月号。我们做推荐可以**做"月度美学主编"——每月邀请一个 KOL / 设计师做 12 张图策展**，用户投票决定下期人选。
2. **B2B Bespoke 是高毛利收入**。Wallpaper* Bespoke 给奢侈品牌做内容 / 展览 / 活动，单笔可达百万级。我们应该把 B2B 内容定制作为核心收入。

## 2. Xiaohongshu / 小红书（RedNote）— **核心参考对象**

### 基础
- 中国社交电商平台，国际名 RedNote。命名来自联合创始人 **Mao Wenchao**（毛文超）的 Bain & Stanford GSB 经历（红色品牌联想）。
- **2023 实现盈利 ~$500M 净利润 / $3.7B 营收**。

### 用户与数据
- **300M+ 月活**。
- **70% post-1990 用户**；2020 女性 ~70%，2022 男性 30%。
- **2024/07 估值 ~$17B**；Hong Kong IPO 潜在估值 **$70B+**。
- 投资者：Alibaba / Tencent / DST Global / HongShan / Hillhouse / Boyu Capital / CITIC Capital。
- **2024 Q4 日均搜索 600M 次**（≈Baidu 的一半）；2025 推出 AI 工具 "Diandian"。

### 内容形态
- 用户生成"种草笔记"（text + image + short video）。
- "种草" → "拔草"模型，KOL 通过真实产品体验驱动购买。
- **研究显示 perceived authenticity → purchase intention 显著相关**。

### 商业模式
- 主要收入：**广告 + 营销服务**（尤其美妆 / 生活方式）
- 核心痛点：用户在 Xiaohongshu 发现，但**实际购买常在 Taobao/Tmall 完成**（流量不闭环）

### 国际化与监管
- **2025/01** TikTok 难民涌入（2 天 700K+ 海外用户），但海外热度快速消退
- **2026/03** 分离中国与海外用户流
- **2026/03** 印度下架（反印宣传指控）
- **2025/09** 中国网信办因"明星八卦 / 负面内容"处罚
- **2025/12** 台湾暂停访问（1,706 起诈骗案）；被批为审查
- **2025/01** 美国 Texas 禁止政府设备使用

### IPO
- 原 2021 美股上市，转回 Hong Kong
- **2026/06 秘密递交 Hong Kong IPO**，Goldman + CICC 承销，state-owned CICC 是潜在投资方

### 可迁移启示
**对一个审美图片推荐产品**：
1. **"种草 → 拔草"是审美推荐的天花板模型**。Xiaohongshu 验证：用户看图决策，但成交在外部。我们的产品可以**做"图 → 购买 → 创作者分成"全闭环**：每张图挂可购买商品链接，5–15% 分成给原作者。
2. **搜索量 600M/天说明"美学 + 搜索"是常态**。小红书用户在搜索"显瘦穿搭 / 上海咖啡"等审美 query。我们应把推荐产品的搜索做成核心入口，**让用户能搜"Tokyo 90s street" 这种美学 query**。
3. **监管风险**：小红书在多个市场遭遇下架 / 限制。审美内容（尤其敏感历史 / 政治相关）需有内容审核系统。
4. **2026 IPO 估值 $70B** 说明"美学 + 推荐 + 电商"在中国市场被高估，但前提是闭环电商成立。
