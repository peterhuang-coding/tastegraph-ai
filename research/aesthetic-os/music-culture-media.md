## 1. Resident Advisor (RA)

### 时间线
- **2001/08/10 由 Paul Clement + Nick Sabine 在 Sydney 创办**，最初聚焦澳洲 dance music。
- 2006 在英国注册公司。
- 2007 开 Berlin 办公室。
- 2014/01 第一次完整网站 redesign，加 mobile。
- 2021/01 第二次 redesign，域名 ra.co。
- 总部 London；办公室：London / Berlin / LA / NYC / Melbourne。
- **100 名员工**（Wikipedia）。

### 产品矩阵
- **RA Magazine** — 在线音乐杂志（news / reviews / films / features / interviews）
- **RA Podcast** — 2006/03/06 首发，第一期 Troy Pierce
- **RA Exchange** — 2010 起播客，访谈艺术家
- **RA Films** — 2011 起，纪录片系列 *Real Scenes*（Bristol / Berlin / Detroit）
- **RA Tickets** — 2008 起，全球夜场票务，face-value 转售系统
- **RA Clubbers Survey** — 行业调查
- **RA Guide** — 2015 iOS app
- **Apple Music** — RA 是 Apple Music 电子音乐 playlist 策展方

### 财务
- **2020/10 从 Arts Council England（Culture Recovery Fund）拿到 £750,000**（COVID 资助）。
- 私有公司，Wikipedia 没有公开收入数据。

### 内容姿态
- **2017 取消 RA Poll**（年度读者投票 top 100 DJs / live acts），理由是"diversity and influence concerns"。
- Album of the Year 历年 winner 列表（2006–2025），是 RA 权威性的核心。

### 可迁移启示
**对一个审美图片推荐产品**：RA 的 "Album of the Year / top lists" 是"美学权威的建立机制"。我们应**每年做"年度图像 top 100" + "视觉风格年度回顾"**，让平台成为某一年美学趋势的**记录者**。记录权 = 权威 = 长尾流量 + 媒体合作。

## 2. NTS Radio

### 时间线
- **2011/04 由 Femi Adeyemi 在 Hackney, London 创办**（不是 2014）。
- 起步预算 £5,000。
- 名字含义 "Nuts To Soup"（Adeyemi 旧 blog 名字）。
- 灵感：pirate radio / MTV2 / 美国大学电台 WFMU / Plastic People 夜店。
- 2013 NTS Live Ltd 注册，首批员工：Shane Connelly / Fergus McDonald / Tabitha Thorlu-Bangura / Padraigh Perkins Edge。
- 现 CEO: **Sean McAuliffe**（原 Plastic People resident DJ）。
- **2023/06 Universal Music Group 入股 25%**（最大股东，部分来源说 25–50% 范围）。

### 收听规模
- **2024/03 ~360,000 日活听众**（NYT）。
- 播出的音乐约 **40% 不在 Spotify** 上（独家 / 小厂牌）。
- **2025/12 月活 6M**（032c 报道）。

### 节目生态
- **700+ resident artists/DJs/producers**，分布在 2 个 live channel，**多数持股份权**。
- Slogan: "Don't Assume"
- Resident 名单包括：Sunn O)))'s Stephen O'Malley / Jamie xx / Haruomi Hosono / Ethel Cain / Clairo / Yaeji / Zack Fox / Show Me the Body / Theo Parrish / Moxie / Jim O'Rourke / Oneohtrix Point Never / Four Tet / Mark Leckey / Floating Points / Martine Syms / Eclair Fifi / Kelsey Lu / Erol Alkan / Moor Mother / Fenriz / Coby Sey / Smithsonian Folkways / The Numero Group / Angel Bat Dawid / Andrew Weatherall
- **Breakfast show**: "The Do!! You!!! Breakfast Show"（Charlie Bones 主持到 2021/08）→ **Flo Dill + Louise Chen**（2024/01 起）
- **"Infinite Mixtapes"**：2018 年末上线，纯音乐 theme stream，**占流媒体 20%**。

### 关键项目 / 联名
- **2018/04 Autechre 4 周驻场**，产出 *NTS Sessions 1–4* 专辑
- **2019 夏 Adidas Originals capsule collection**（Slogan "Don't Assume"，Lee "Scratch" Perry 83 岁代言）
- **2019/06 Warp Records 30 周年 takeover**（~100 小时）
- Blue Note 80 周年 takeover
- **2019/09 NTS/Netflix workshop**（Jenn Nkiru / Skepta's Grace Ladoja / Top Boy 演员 Ashley Walters + Micheal Ward）
- **2020/02/19 Arca 62-min 单曲 @@@@@ 在 *DIVA EXPERIMENTAL FM* 首播**
- **2020/05/02 "Remote Utopias" 24 小时慈善 broadcast**（Erykah Badu / Tame Impala / Jonah Hill / JME / Jorja Smith / Wolfgang Tillmans / Bladee / Ecco2k / Mica Levi）
- **2021 10 周年策展**：Matt Groening / Amaarae / My Bloody Valentine / Mica Levi / Liz Johnson Artur / Dopplereffekt / Theo Parrish / Laurie Anderson / Arca
- **Tate Modern Tate Lates 月度策展**（Uniqlo 赞助）
- **"Work In Progress" 艺术家发展项目**（与 Carhartt + Arts Council England），首年 9,000+ 申请者
- 全球 live events / club nights（London 为主）

### 品牌合作方
- **Netflix / Rockstar Games / SONOS / YouTube Music / Adidas / Carhartt / Uniqlo（Tate Lates 共赞助）**

### 奖项
- 2014: "Best Online Radio Station in the World" — Mixcloud / International Radio Awards
- 2018: Femi Adeyemi — AIM Independent Music Awards "Indie Champion"
- 2019: Outstanding Contribution — DJ Mag Best of British

### 可迁移启示
**对一个审美图片推荐产品**：
1. **NTS 模式：把"主理人"做成股东**。700+ resident DJs 多数持股 → 内容生态稳定、用户黏性极强、明星主动参与。我们做推荐产品应该**把"高活跃美学贡献者"做成平台合伙人 / 期权池**，而不是单纯 KOL 合同。
2. **"Don't Assume" + "40% 不在 Spotify"** = 差异化是 NTS 命根。我们的推荐产品要**主动避开主流图站（Instagram / Pinterest 热门），做"小众美学策展"**。差异化比流量重要。
3. **"Adidas × NTS × Lee Scratch Perry"** 是典型品牌合作模式——大品牌想要 NTS 受众 + NTS 美学认证，NTS 拿到钱 + 不稀释调性。我们可以**做"Aesthetic × Brand Drops"**，每个 drop 都是品牌付钱 + 平台做美学策展 + 用户买到限定商品。

## 3. Boiler Room（补充，替代 Wooozy）

### 事实
- 2010 London 由 **Blaise Bellville** 创办。
- Wikipedia 词条仅一句话："music broadcaster launched in London in 2010"。
- 详细财务 / 所有权信息需补充。

### 可迁移启示（推断）
- Boiler Room 早期以 bedroom DJ 视频直播出名，已被 Adidas / Red Bull 等长期赞助。
- 与 NTS Radio 形成对照：**Boiler Room 是 "video / 视觉化演出"，NTS 是 "audio / radio"**。
- 对推荐产品启示：**视觉化策展比纯文字策展转化率更高**。
